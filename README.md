Leonida Legend is an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words that cites its sources, a five-stage roadmap to the platinum, a missable-timeline warning for the one trophy that can be lost, and a checklist that saves in the browser with export and import. Written after the game's 19 November 2026 launch, it resolves three of the five trophies that were unconfirmed before release (Capital Offense, The Truth Is Out There, and the method behind In The Beginning…) and says honestly which two are still unconfirmed.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network needed — the app is static files under `app/`.
